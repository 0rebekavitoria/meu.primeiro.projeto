💻 PROA TRANSFORME-SE – Mundo da Programação

Este projeto foi desenvolvido durante meus estudos no **curso de Programação Front-End pelo PROA Projeto Transforme-se**.

O código apresenta uma estrutura básica em **HTML**, contendo título da página, cabeçalhos e organização inicial de um site simples sobre o **mundo da programação**.

## 🚀 Tecnologias utilizadas
- HTML5

## 📚 Aprendizados
Neste projeto estou praticando:
- Estrutura básica do HTML
- Uso de tags (`html`, `head`, `body`, `title`, `h1`)
- Organização inicial de páginas web
- Desenvolvimento Front-End
